#### 🌴 Oil Palm Fruit Ripeness Classification: ResNet-50 + CBAM
A deep learning model that classifies the ripeness of oil palm fresh fruit bunches (*unripe, ripe, overripe*) using **3,375 images**. It is built on a ResNet-50 architecture enhanced with the **CBAM** attention module.

| Data Split | Accuracy | Macro F1-Score |
|---|---|---|
| 80:10:10 | 96.00% | 96.00% |
| 90:10 | **99.12%** | **99.12%** |

`Python` `TensorFlow` `Keras` `CBAM` `ResNet-50` `Transfer Learning`
📂 **[View Repository](https://github.com/Kawankita/sawit-resnet50-cbam)**
